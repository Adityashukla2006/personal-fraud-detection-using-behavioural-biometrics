# results/figures

Generated plots, written by the scripts in `ai-models/experiments/` and by the measurement scripts
for the deployment.

Figures expected here:

- The headline figure: poisoning resistance against false rejection rate under genuine drift, with
  one curve each for static profile, naive update and guarded update.
- ROC curve over the 51 CMU subjects, with the published baseline marked.
- Profile displacement over successive poisoning sessions, per update policy.
- Detection rate per attack class (bot typing, replay, impostor).
- End to end scoring latency distribution, warm and cold invocations plotted separately.

Figures are regenerated by script, not edited by hand.
