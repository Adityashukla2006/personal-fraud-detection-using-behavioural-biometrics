    Try a scenario

    Scenarios are seeded from a terminal with admin credentials, so the deployed permissions stay exactly as designed. From the repository root:

    python simulator/demo_scenarios.py takeover --email you@example.com

    Mismatched typing profile: your next transfer on that device class is held for a passkey step-up.

    python simulator/demo_scenarios.py flagged-payee --account 123456789

    Flagged payee: transfers to that account are restricted and appear here with a Release button. With takeover as well, they are blocked.

    python simulator/demo_scenarios.py enrolled-device --email you@example.com

    Enrolled device: a passkey step-up there earns full trust, so adaptation learns from it.

    python simulator/demo_scenarios.py clear --email you@example.com --account 123456789

    Pick a user to see their decisions, transfers and adaptation state.
