## Thematic synthesis

The fifteen papers group into four clusters.

**Cluster 1: Behavioural biometric modelling (papers 1, 2, 3, 6, 11).** These papers extract
behavioural features, typing and swipe dynamics chiefly, and evaluate detection performance across
supervised and deep models. Their common limitation is that the work stops at the model: there is no
serving architecture, no latency budget and no throughput measurement.

**Cluster 2: Cloud and streaming fraud architectures (papers 7, 8, 15).** These papers build scalable
pipelines, event driven microservices and streaming analytics for real time fraud detection. Their
payload is the transaction record, and behavioural signal is largely absent from the architecture.

**Cluster 3: Explainability and privacy preserving learning (papers 9, 10, 14).** These papers
address transparency through post hoc explanation and privacy through federated training. The
federated work assumes a multi institution ecosystem that most banks lack, and the explainability
review proposes no new model.

**Cluster 4: Identity verification, continuous authentication and adaptive surveys (papers 4, 5, 12, 13).**
These papers cover onboarding and KYC verification, continuous authentication and user profiling, and
surveys of adaptive multimodal systems. The reviews and surveys describe adaptive profiling as
desirable but are not experimentally validated.

**The shared blind spot: update security.** Papers 1, 3, 11, 12 and 13 recommend adaptive profiling
to control false positives. None analyses the security of the update rule. If a system updates a
user's reference profile from sessions it scores as genuine, then an adversary with valid credentials
can submit sessions engineered to fall just inside that threshold, shifting the profile incrementally
toward their own behaviour. Over enough sessions the adversary becomes the enrolled user, and the
system has been taught to accept them. The literature presents adaptivity as a pure improvement over
static profiles; this project argues it is a tradeoff and measures both sides of it. This blind spot
becomes gap RG3, the primary research gap, in [research-gap.md](research-gap.md).
